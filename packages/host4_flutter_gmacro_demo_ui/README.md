# host4_flutter_gmacro_demo_ui

Shared GMacro demo UI used by:

- `examples/host4_gmacro_demo`
- `examples/host4_flutter_demo`

This package contains only demo/debug UI for BLE, iOS MFi, Android USB,
GMacro session logging, OTA test, unified input debug, and API test pages.
It is intentionally separate from the production `host4_flutter_gmacro` API
package.
